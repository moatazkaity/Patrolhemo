# بترولي | Petroli
تطبيق ويب عربي لتسجيل مصروفات تعبئة الوقود، يعمل على الهاتف ويمكن تثبيته كـ PWA.

## الوظائف
- تسجيل عدد اللترات واختيار ممتاز (أخضر) أو محسن (أحمر فاتح).
- تسجيل تاريخ ووقت الحفظ تلقائيًا حسب ساعة الهاتف.
- احتساب التكلفة بناءً على السعر الحالي، مع حفظ سعر اللتر داخل كل سجل حتى لا يتغير تاريخيًا.
- تقرير من تاريخ إلى تاريخ (يشمل اليومين بالكامل)، مع مجموع المصروفات واللترات والتعبئات وتفصيل النوعين.
- حذف التعبئات بعد تأكيد المستخدم.
- تصدير واستيراد نسخة احتياطية JSON.
- يعمل دون اتصال بعد فتحه أول مرة على GitHub Pages.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا باسم Petroli على GitHub.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع (وليس ملف ZIP نفسه).
3. افتح Settings > Pages > Build and deployment، واختر Deploy from a branch، ثم main و / (root) واضغط Save.
4. انتظر ظهور رابط Pages ثم افتحه على الهاتف.
5. من متصفح Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

## ملاحظات
- لا يحتاج خادمًا أو حسابًا، والبيانات تحفظ في localStorage على الجهاز والمتصفح نفسه؛ لا تنتقل تلقائيًا بين الأجهزة.
- يُرجى تصدير نسخة احتياطية بانتظام، خصوصًا قبل حذف بيانات المتصفح.
- الأسعار الافتراضية صفر، ويجب ضبطها من الإعدادات قبل تسجيل تعبئة.
- هذا مشروع PWA وليس APK أصليًا.
